帮助与反馈

支持

安装、授权或行程导入遇到问题时，可以先查看以下说明，或直接联系开发者。

安装与更新

「出行」不通过 Google Play 分发。正式版本仅通过项目的 GitHub Releases 发布。请核对 Release Notes 中公布的 APK SHA-256，不要从不明来源下载安装包。

邮箱同步

  • 邮箱同步需要用户自行配置支持 TLS IMAP 的邮箱，完成首次手动同步后，可在设置中开启定期自动同步。
  • 可以指定服务器提供的同步文件夹。请参考邮箱服务商文档自行配置收信规则或过滤器，确保新的铁路通知进入所选文件夹。
  • 请使用邮箱服务商提供的专用密码或客户端授权码，不要填写邮箱登录密码。
  • 当前支持 Gmail、QQ 邮箱、163 邮箱、126 邮箱和自定义 IMAP 服务器，但账号策略可能限制第三方客户端。Gmail 用户可前往 Google 应用专用密码 页面检查账号是否可用。
  • 当前识别购票、改签、候补兑现和退票通知，首次同步完成后，后续同步只读取新增邮件。
  • 如果无法配置邮箱，可改用粘贴邮件正文或截图导入。
  • 首次同步或重建索引时，可以选择仅同步未出发行程，或导入历史行程并直接归档。
  • 解析结果必须由用户确认后才会保存。

截图导入

应用通过 Android 系统照片选择器读取本次选中的截图，不申请整个照片库权限。OCR 在设备端完成。图片清晰度、裁剪范围和页面格式可能影响结果，识别后请检查文字和行程字段。

提醒权限

行程提醒默认关闭。开启提醒时，Android 可能要求通知权限以及「闹钟和提醒」特殊权限。后者用于准时安排乘车提醒，不会在系统时钟应用中创建闹钟。

Google Wallet

Google Wallet 是可选导出功能，不承担主要提醒职责。卡片只包含基本乘车信息，不包含动态检票二维码。如果无法添加，请确认设备已安装并登录 Google Wallet，并使用由 NeKo7inA 正式签名的 Release APK。

删除数据和撤销授权

  • 在行程详情中可以删除单个本地行程
  • 在 Android 系统设置中清除应用数据，可以删除全部本地数据
  • 卸载应用会移除设备上的应用数据
  • 可以在应用设置中删除邮箱配置，并在邮箱服务商处撤销专用密码或授权码
  • 已添加的 Google Wallet 卡片需要在 Google Wallet 中单独删除

问题反馈

请发送邮件至 7@neko7ina.com。也可以在 GitHub Issues 提交不包含隐私信息的问题。

请勿发送：邮箱密码、授权码、完整邮件、身份证件、动态检票二维码、签名文件或其他敏感凭据。必要时请对订单号、姓名和座位信息进行遮盖。
