这一版调整出门提醒的行为：它本来是出发前几小时的提醒，看一眼就该出门了，看完应该能直接关掉。此前点「已上车」会结束提醒并归档行程，划掉后还会再次弹出。现在按钮改为「已读」，划掉或点击后不会再弹。临近发车的实时提醒不受影响。

## 改进

- **出门提醒看后即关**：发车前提醒的按钮从「已上车」「取消提醒」换成单个「已读」，点击只关闭这条通知，不结束提醒、不归档行程。
- **划掉后不再重弹**：出门提醒触发过一次后，重新开机、邮箱同步导入新行程或修改提醒时间，都不会把它再次架上并弹出。

## 问题修复

- **出门提醒反复弹出**：出门提醒触发后，开机重排提醒、邮箱同步或修改提醒设置会让它立刻再弹一次，直到发车前可能反复打扰。

临近发车的实时提醒保持原样：发车前半小时内的「即将发车」倒计时通知仍提供「已上车」和「取消提醒」，「已上车」结束提醒并归档行程。

已保存的行程数据、邮箱配置和 Google Wallet 卡片不受影响，可以直接覆盖安装。
