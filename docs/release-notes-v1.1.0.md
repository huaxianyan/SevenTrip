这一版新增出行概况首页和三项底栏，行程页的切换方式与归档操作也有调整。已保存的行程数据、邮箱配置、提醒设置和 Google Wallet 卡片不受影响，可以直接覆盖安装。

## 新功能

- **出行概况**：首页显示下一趟行程、发车时间和实时倒计时，并统计出行次数、常坐线路和走过的车站数。
- **三项底栏**：新增「首页」「行程」「设置」三项底栏，原先收在首页右上角菜单里的设置可以直接看到。

## 问题修复

- **同一线路被拆成两条**：12306 在 2020 年前后对车站名的写法不一致，老邮件不写「站」，新邮件写，导致「镇江 → 上海」和「上海站 → 镇江站」算成两条线路，「走过车站数」也把同名车站重复计数。
- **首页留白**：有历史记录但没有未出发行程时，首页整块不渲染，留出一片空白。

## 改进

- **页内切换**：历史行程改为行程页内的切换，支持左右滑动，标签栏跟随滑动实时更新。
- **归档手势**：未出发卡片的归档由左滑改为长按菜单，横向手势交给翻页。

本地保存的行程仍保留邮件中的原始车站名写法，去掉末尾「站」只发生在展示和统计。

逐版本改动见 [更新记录](https://github.com/huaxianyan/SevenTrip/blob/v1.1.0/CHANGELOG.md)。

「出行」是独立应用，与 12306 及中国铁路无关联。请勿在公开 Issue 中提交邮箱密码、授权码、完整邮件、订单号或身份证件。
