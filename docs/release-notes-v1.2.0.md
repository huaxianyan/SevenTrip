# 出行 v1.2.0

这是一次功能更新，改动集中在邮箱自动同步：同步扫到的铁路行程会直接写入本地记录，不再需要手动确认。已保存的行程数据、邮箱配置、提醒设置和 Google Wallet 卡片不受影响，可以直接覆盖安装。

## 下载与安装

安装文件将在本 Release 的 Assets 中提供：

```text
chuxing-1.2.0.apk
```

系统要求：Android 8.0 或更高版本。

已经安装 `v1.0.1` 或 `v1.1.0` 的用户可以直接覆盖安装，本地数据会继续保留。

## 更新内容

### 自动同步改为直接保存

- 后台自动同步扫到的行程**直接保存到本地记录**，不再弹出需要手动确认的提示。
- 保存完成后再发一条通知告知结果，例如「已添加 2 条行程」配「镇江 → 上海 等」。
- 点击通知直接落到行程页的「未出发」列表，下次打开应用也能立刻在首页「下一趟行程」和行程页看到。
- 从升级前遗留的待确认行程会在下次打开应用时自动补存，不会一直卡在待确认状态。

这是行为变化：**v1.1.0 及更早版本**在同步发现行程后会先停下等你在应用内确认，确认之前不会写入记录，期间后续同步也会被挡住。现在这一步去掉了。

### 同步结果页

- 同步结果页从「检查后导入」改为结果展示，少一步点击，按钮由「检查并导入 N 个行程」改为「完成」。
- 改签、退票无法唯一对应原车票这类警告不再拦住保存，行程照常写入，警告仍在结果页展示，方便核对。
- 首次同步仍保留「仅同步未出发」和「导入历史行程并直接归档」的选择，这一步决定导入范围，不能省略。
