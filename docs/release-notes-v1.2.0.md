这一版改动集中在邮箱自动同步：同步扫到的铁路行程会直接写入本地记录，不再需要手动确认。同时修掉了无座票和卧铺票解析失败的问题，这类邮件此前会被整条丢弃。已保存的行程数据、邮箱配置、提醒设置和 Google Wallet 卡片不受影响，可以直接覆盖安装。

## 主要更新

- **同步后直接保存**：后台自动同步扫到的行程直接写入本地记录，不再弹出需要手动确认的提示。
- **通知告知结果**：保存完成后发一条通知，文案带出结果和路线，例如「已添加 2 条行程」配「镇江 → 上海 等」。
- **结果页简化**：同步结果页从「检查后导入」改为结果展示，按钮由「检查并导入 N 个行程」改为「完成」。
- **警告不再拦截**：改签、退票无法唯一对应原车票这类警告不再拦住保存，行程照常写入，警告仍在结果页展示。
- **无座票可以识别**：12306 把无座票写成 `11车无座`，座位值后面没有「号」。旧规则把「号」当成必需字符，整条车票信息匹配不上。
- **卧铺票可以识别**：卧铺写成 `3车12号下铺`，同样没有紧跟在座位值后面的「号」，一并修掉。有座票的抓取结果不变。
- **历史邮件会重新解析**：解析器版本从 2 提到 3，下次同步会重扫邮箱里的历史邮件，之前漏掉的记录会补回来。

同步后直接保存是行为变化。v1.1.0 及更早版本在同步发现行程后，会先停下等你确认，确认前不写入记录，期间后续同步也会被挡住。现在这一步去掉了。首次同步仍保留「仅同步未出发」和「导入历史行程并直接归档」的选择，这一步决定导入范围。

升级后打开应用，在设置里手动点一次邮箱同步，历史记录就会补齐。重扫按订单整组覆盖，不会产生重复行程，也不会把已经归档的行程翻回未出发。

完整实现与验收记录见 [更新记录](https://github.com/huaxianyan/SevenTrip/blob/v1.2.0/CHANGELOG.md)。

「出行」是独立应用，与 12306 及中国铁路无关联。请勿在公开 Issue 中提交邮箱密码、授权码、完整邮件、订单号或身份证件。
