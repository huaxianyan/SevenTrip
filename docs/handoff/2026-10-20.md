# 2026-10-20：发布产物命名、站点链接与签名目录随仓库改名收口

## 当前主线

- 仓库：`huaxianyan/SevenTrip`，分支 `main`，本轮起始基线 `e1e1720`。
- 线上最新版本 `v1.3.0`，未发新版；本轮只动发布流程、站点与文档，不动代码，不递增 `versionCode`。

## 本轮改动

- 发布工作流：资产名由 `chuxing-<版本>.apk` 改为 `SevenTrip-<版本>.apk`（`7dcea09`），并去掉 `gh release create` 上的 `#Android APK`、`#SHA-256` 两个显示标签（`0601b57`）。
- 历史五个 Release 的资产逐个改名，校验文件内容同步，标题与正文保持原样，线上标签已清空。改名前带 `Android APK` 标签，页面上盖住了文件名，五个版本看起来是同一个名字。
- 站点与文档里的旧仓库名 `huaxianyan/WalletAssistant` 改为 `SevenTrip`：`site/index.html`、`site/support/index.html` 两处、`docs/cloudflare-pages.md`（`e1e1720`）。
- 签名目录统一用项目名：本机 `~/.android/signing/SevenTrip` 由 `WalletAssistant` 改名，NAS 同名，`.github/workflows/release.yml` 与 `app/build.gradle.kts` 两处路径同步，`docs/signing.md` 与密钥包内的 `RECOVERY.txt` 一并更新。
- 包名 `com.neko7ina.wallet.assistant`、签名证书、keystore 文件名 `wallet-assistant-release.p12` 与别名 `wallet-assistant-release` 一律保持原样：包名与签名是 Google Wallet 登记的调用方身份，改了 Wallet 卡片加不上，老用户也无法覆盖安装。理由记在 `DECISIONS.md`。
- 规范侧（`Skills/release-notes-standard`）新增「发布资产不设显示标签」，来源是本轮这个发现（`6f31e5a`）。

## 验证

- 历史 Release 逐个比对，资产数量与产物字节数不变；抽包实测 SHA-256 与校验文件记录逐位一致。
- `./gradlew :app:help` 本机配置通过。`wallet.properties` 在 `app/build.gradle.kts` 里是硬校验（`check(...)`），路径不对直接失败，所以这一条同时覆盖了目录改名与两处路径改动。
- 五个仓库线上已无带显示标签的资产。
- 三个中文门禁在改动的文档上全过。
