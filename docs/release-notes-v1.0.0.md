「出行」是一款在 Android 设备端导入、整理和提醒铁路行程的独立应用。首个正式版本，支持 12306 购票、改签、候补兑现和退票邮件、截图 OCR、本地行程管理、精确提醒和可选的 Google Wallet 导出。

## 主要更新

- **导入行程**：配置 TLS IMAP 邮箱后读取 `12306@rails.com.cn` 的铁路通知，识别购票、改签、候补兑现和退票邮件，首次同步读取历史邮件，之后只读新增邮件。
- **截图导入**：通过 Android 系统照片选择器导入截图，用设备端 ML Kit 中文 OCR 识别文字，也可以直接粘贴订单通知正文。
- **管理行程**：行程保存在设备端，可查看、删除、归档和恢复，同订单的不同车次拆成独立行程，已改签和已退票状态会保留。
- **乘车提醒**：按发车时间安排精确提醒，通知提供「已上车」和「取消提醒」两个操作。
- **Google Wallet**：可以把已确认的最少行程信息添加为 Generic Pass，不包含也不模拟 12306 动态检票二维码。

应用不通过 Google Play 分发，安装时需要允许安装未知来源应用。后续版本必须使用相同 Release 证书且 `versionCode` 更高，才能覆盖安装并保留本地数据。

邮箱凭据在设备上加密保存，行程保存在应用私有数据库中，不纳入 Android 应用数据云备份。

权限、隐私与支持范围见 [README](https://github.com/huaxianyan/SevenTrip/blob/v1.0.0/README.md)，逐版本改动见 [更新记录](https://github.com/huaxianyan/SevenTrip/blob/v1.0.0/CHANGELOG.md)。

「出行」是独立应用，与 12306 及中国铁路无关联。请勿在公开 Issue 中提交邮箱密码、授权码、完整邮件、订单号或身份证件。
